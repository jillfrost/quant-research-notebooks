# Quant Research Notebooks

A collection of Python notebooks, exercises, and mini projects exploring quantitative trading and financial research.

I’m using this repository to develop my understanding of market mechanics, portfolio construction, trading strategies, and performance evaluation.

## Topics

- Market mechanics and execution
- Forwards and futures
- Risk, returns, and portfolio analysis
- Trend-following and momentum strategies
- Backtesting and statistical evaluation

## Organization

- `notebooks/`: Exercises and research analyses
- `src/`: Reusable Python functions
- `tests/`: Checks for calculations and portfolio logic
- `data/`: Data documentation and small example datasets

## Setup

Install dependencies:

```bash
uv sync
```

Launch JupyterLab:

```bash
uv run jupyter lab
```

## References

Initial studies follow *Quantitative Trading Strategies Using Python* by Peng Liu. Individual notebooks distinguish book-based examples from original extensions.

## Status

Work in progress. Findings reflect the assumptions and limitations documented in each analysis.
